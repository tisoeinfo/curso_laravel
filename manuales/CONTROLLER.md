# Controller
El Controller recibe las solicitudes del usuario, procesa la petición y coordina con la clase correspondiente para obtener o modificar los datos.

## Métodos principales
- `index()` → Obtener listado.
- `show()` → Obtener un registro específico.
- `store()` → Crear un registro.
- `update()` → Actualizar un registro.
- `destroy()` → Eliminar un registro.


# POO
- modificadores de acceso o visibilidad: 
private, public, protected → modificadores de acceso/visibilidad.
Cliente, string → tipos de datos de la propiedad.
